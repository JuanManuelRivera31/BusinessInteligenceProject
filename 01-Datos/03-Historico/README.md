# 03-Historico

Esta carpeta no la lee Power BI. Sirve para guardar duplicados y versiones anteriores.

## Contenido

- `2025/2025-01/teatro-duplicado.xlsx`: copia del archivo duplicado de Teatro del Semestre 1. Se conserva como evidencia; no se carga en el modelo.
- `2025/2025-02/danza-urbana-copia-salsa.xlsx`: copia del roster de Salsa S2 que estaba en la carpeta de Danza Urbana. Se conserva como evidencia; no se carga en el modelo.

## Reglas

1. Si un archivo se reemplaza por una versión nueva, mover la versión anterior aquí.
2. Si se detecta un duplicado exacto, moverlo aquí en lugar de dejarlo en `01-Crudos`.
3. Mantener la misma estructura de años y semestres.
4. No conectar Power Query a esta carpeta.
